# PratoTextile

Release statico di PratoTextile per GitHub Pages.

La piattaforma presenta tre aree: forum professionale moderato, magazine/newsletter editoriale e vetrina di organizzazioni tessili. Al rilascio iniziale non pubblica discussioni, aziende, dati di mercato, eventi o iscrizioni: ogni area resta visibile solo dopo verifica, moderazione e configurazione dei relativi servizi.

Il workflow GitHub Pages pubblica esclusivamente il contenuto di `site/`.
